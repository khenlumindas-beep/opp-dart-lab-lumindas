## Description

An interactive Dart console program that models school personnel using
Object-Oriented Programming principles:

- **Encapsulation** — private fields with getters/setters and age validation
- **Inheritance** — `Student` and `Teacher` extend `Person`
- **Polymorphism** — `School.introduceAll()` calls the correct overridden
  `introduce()` for each object

All data is entered by the user through `dart:io` — no hardcoded records.
